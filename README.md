# PROOFLY LEARN

Learn anything. Build your future.

PROOFLY LEARN is a multilingual learning platform designed to help learners discover free online courses, explore educational resources, save their favorite courses, and track their learning progress.

## Features
- 🔎 Search courses by title and description
- 📚 Explore courses across multiple categories
- 🌍 Multilingual interface: English, Arabic, French, Spanish, and Portuguese
- 🌙 Dark and light themes
- ⭐ Save favorite courses
- 📈 Track learning progress and goals
- 📱 Responsive design for desktop and mobile

## Tech Stack
- Next.js
- React
- TypeScript
- CSS

## Vision
Make quality education more accessible by helping everyone discover the right learning resources.
